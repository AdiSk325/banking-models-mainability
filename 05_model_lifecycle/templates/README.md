## Jak Korzystać z Szablonów

1. Skopiuj wybrany plik szablonu do folderu projektu
2. Uzupełnij pola `[PLACEHOLDER]` i sekcje `<!-- PROMPT -->` treścią
3. Usuń wskazówki dla autora przed finalizacją dokumentu
4. Oznacz dokument wersją (v1.0, v1.1) i datą
5. Zapisz jako PDF lub w systemie dokumentów organizacji
