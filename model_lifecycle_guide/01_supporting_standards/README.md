## Naming Convention

All standards follow the naming: `STD-NNN_descriptive_name.md`

Each standard document should contain:
1. Purpose and scope
2. Applicable models / tiers
3. Detailed requirements
4. Roles and responsibilities specific to the standard
5. Linked procedures and templates
6. Version and approval information
