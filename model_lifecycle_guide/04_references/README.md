## How to Add a Reference

For each reference entry, use the following format:

```markdown
### [Short Title]
- **Source:** Full citation (author, organisation, year)
- **URL / Location:** Link or internal path
- **Relevance:** Which sections of the Guide this informs
- **Key takeaways:** 2–3 bullet points on what to extract
- **Added by:** [name/initials] | **Date:** [date]
```
