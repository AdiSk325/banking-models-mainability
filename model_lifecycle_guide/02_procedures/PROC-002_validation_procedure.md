## Purpose

This procedure provides step-by-step instructions for conducting independent model validation, from receipt of the validation handover package through to issuance of the Validation Report and findings closure.

---

## Scope

All models requiring independent validation per [STD-003](../01_supporting_standards/STD-003_validation_standard.md). Covers initial validation and revalidation (for material changes and periodic revalidation).
