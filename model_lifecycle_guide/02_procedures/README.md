## Naming Convention

All procedures follow the naming: `PROC-NNN_descriptive_name.md`

Each procedure document should contain:
1. Purpose
2. Scope
3. Roles involved
4. Step-by-step instructions
5. Decision points and conditions
6. Required forms / templates
7. Version information
