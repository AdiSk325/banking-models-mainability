# Chapter 6 — Stage Requirements: Navigation

> **Section:** Model Lifecycle Guide, Chapter 6

## Overview

This section contains a dedicated file for each stage of the model lifecycle. Each stage file follows the standard section template and describes:

- **Purpose** of the stage
- **Entry criteria** — what must be in place before the stage begins
- **Key activities** — what happens during the stage
- **Roles** — who is responsible
- **Required outputs / artifacts** — what must be produced
- **Exit criteria / stage gate** — what must be satisfied to proceed
- **Linked documents** — standards, procedures, templates
